# US Product Language Guide

## Core terminology

- Use `prediction` instead of `bet` whenever possible in user-facing copy.
- Use `prediction amount` or `AP committed` instead of gambling-heavy wording.
- Use `potential return` instead of `potential winnings` in core product UI.
- Use `club` for player organizations inside ArenaX.
- Use `team` only for esports teams participating in matches.
- Use `reward` for platform incentives and progression unlocks.
- Use `prize` only for catalog or store-style redeemable items if needed.

## Tone

- Clear, competitive, premium
- Short, direct CTA labels
- Avoid mixed gaming metaphors unless they are central to the product
- Prefer English-first copy with US-friendly date and phrasing conventions

## Approved examples

- `Make a prediction`
- `Potential return`
- `Club challenge`
- `Level rewards`
- `Recent activity`
- `Get started`
- `Explore matches`

## Avoid

- `Place a bet`
- `League account` when the product brand is ArenaX
- mixed French/English labels on the same page
- inconsistent `club` / `guild` / `team` wording for the same concept
