# ArenaX Demo Readiness Shortlist

## Goal

Run a fast, clean product demo without getting lost in secondary flows.

## Before The Demo

- Start the app on the expected port.
- Confirm the landing page loads without hydration or runtime overlays.
- Use a seeded or local QA session with visible profile data, rewards, streak, and live calls.
- Keep one browser tab on the app and one fallback tab on `/dashboard`.

## Recommended Demo Path

1. Home `/`
2. Login `/login`
3. Dashboard `/dashboard`
4. Live Calls `/live-calls`
5. Clubs `/clubs`
6. War Map `/war-map`
7. Leaderboard `/leaderboard`
8. Profile `/profile`
9. Rewards `/rewards`

## What To Say

### Home

- ArenaX is not just a dashboard.
- It is a live competition layer built around clubs, prestige, and daily return loops.

### Login

- The platform is community-first.
- Discord is the natural primary path, with Twitch as the creator-facing secondary path.

### Dashboard

- This is the daily cockpit.
- The player sees immediately what matters today: streak, challenge, rewards, and momentum.

### Live Calls

- This is the habit loop.
- Live pressure, clear reward framing, and repeatable daily missions create return behavior.

### Clubs

- Clubs create gravity.
- The product becomes social, competitive, and identity-driven instead of solitary.

### War Map

- The world moves even when the player is offline.
- That makes the game state feel alive and worth checking again.

### Leaderboard

- Prestige is visible and public.
- Players come back to defend position, not just consume content.

### Profile

- The profile is a status object.
- It turns progression into something the player wants to grow and protect.

### Rewards

- Rewards make progression tangible.
- The vault gives players a reason to convert momentum into value.

## Manual Checks Right Before Presenting

- Home CTA clicks work.
- `Sign In` and top nav work.
- Dashboard opens without redirect loops.
- Live Calls filters respond.
- Clubs page cards render cleanly.
- War map renders with no blank panel.
- Leaderboard filters respond.
- Profile shows streak, progress, and badges.
- Rewards page shows progression and catalog.

## If Something Goes Wrong

- Return to `/dashboard`.
- Avoid debugging live in front of the audience.
- Reframe the story around the product loop:
  - daily return
  - club identity
  - prestige
  - rewards

## Best One-Line Positioning

ArenaX turns esports attention into a daily ritual built on club loyalty, live pressure, public prestige, and reward momentum.
